# Website Replica 源码包合同

## 根目录

ZIP 根目录就是项目根，不增加仓库名或任意外包装目录。必须存在精确根级普通文件 `VICEME-REPLICA.md`；大小写、连字符和扩展名不可变化，也不能用 `docs/` 下的同名文件替代。

部署文档必须是非空 UTF-8 文本且不超过 256 KiB，至少准确记录：

- 支持的操作系统、运行时、包管理器及精确版本约束；
- 从干净目录安装依赖、执行迁移、构建、测试和启动的命令；
- 需要的环境变量名称、用途和取得方式，但绝不包含真实值；
- 端口、持久化目录、外部服务和部署平台要求；
- 部署后健康检查、关键页面验证和安全回滚步骤。

不得写未经实际验证的命令。Agent 应在与目标仓库一致的本地环境运行文档中的可执行步骤；无法验证的边界必须明确标为未验证，不能猜测。

## 完整源码

包含复现网站所需的源码、锁文件、公开静态资源、数据库 schema 与 migration、安全配置示例和部署配置。排除：

- `.git`、依赖缓存、测试缓存和可重建的临时输出；
- `.env`、`.env.*` 真实环境文件、私钥、证书、访问令牌、Cookie、数据库转储和云服务凭据；
- 用户数据、日志、上传内容和机器专属绝对路径；
- ViceMe 本地恢复目录、许可证文件或任何 `.viceme` 根命名空间。

安全的 `.env.example` 可以保留，但只能包含变量名和无敏感性的占位值。若无法判断某个文件是否包含 secret，停止并让用户处理，不能默认上传。

## 发布前检查

1. 确认归档不超过 100 MiB。
2. 列出根目录和部署文档，确认没有外包装目录。
3. 搜索高风险凭据文件和明显 secret；命中时停止。
4. 从归档内容而非工作树运行一次部署文档中的安装、构建和测试步骤。
5. 向用户展示归档范围、排除项和全部未验证边界，再取得不可变发布确认。

平台 API 会重新校验 ZIP 结构、路径、容量、CRC 和部署文档；本地检查不能替代服务端权威门禁。
