# Bonjour Card

这是由 Agent 对话整理资料的只读个人名片模板。保留既有的两栏布局、间距、分割线、标签、标题与副标题；页面只用于查看资料、作品和公开联系方式，以及打开已有链接。

**使用本模板前必须完整阅读 [DESIGN.md](DESIGN.md)。** 复制整个项目作为起点，只替换已经由用户确认公开的资料和卡片数据；禁止从空白页面重新生成，也不要把模板当作可以自由发挥的视觉灵感。

## 已实现

- 作品卡与公开联系方式卡：有有效 URL 时可查看并打开链接；站内作品保留实际使用的站内跳转。
- 姓名、头像、简介、标签、作品与联系方式均由 Agent 在对话中收集、整理并写入页面数据。
- 桌面与手机响应式布局，以及键盘可关闭的链接查看弹窗。

## 运行

```bash
npm install
npm run dev
```

构建生产包：

```bash
npm run build
```

## 作为模板复用

1. 把整个目录复制到用户工作区，不另建页面或替换技术栈。
2. 先完整阅读 `DESIGN.md`，再运行 `npm ci` 与 `npm run build`（需要 Node.js 20.19+ 或 22.12+）。
3. 由 Agent 在对话中确认资料和公开范围，再更新示例资料、作品链接、联系方式、封面和头像。
4. 展示构建产物的本地嵌套路径预览；源码结构和 `src/styles.css` 是唯一视觉依据，不看图重做。
5. 上传的是包含 manifest、HTML 入口与资源的静态产物；页面本身不保存浏览器草稿，也不读取运行时平台资料。

## 边界

- 这是前端静态模板，压缩包包含 `index.html`、完整源码与依赖锁定文件；不含 `node_modules`。
- 不含登录、数据库、部署服务或数据抓取。
- 不提供视频、文字、图片墙或其他 Block；媒体在本期特指公开联系方式。
- 联系方式不做自动抓取；链接和邮箱仅作为用户主动确认公开的入口。
- 公开发布时请继续使用自己的名称、图标和文案，不要以 Bonjour 官方模板或合作产品进行宣传。
