# Profile Blocks Template

汪奕辰提供的个人主页 Block 编辑器原型，经本期业务范围收窄后的唯一参考模板。它保留原版
间距、分割线、标签、标题与副标题、添加 Block、作品导入、编辑按钮和图标，不使用 Bonjour
的名称、商标或素材。

**使用本模板前必须完整阅读 [DESIGN.md](DESIGN.md)。复制整个项目作为起点，只替换用户资料
和 Block 内容；禁止从空白页面重新生成，也禁止把它理解为可以自由发挥的视觉灵感。**

## 已实现

- 作品 Block：点击“导入作品”后先生成占位卡；点击卡片可填链接、名称、简介和封面。
- 媒体与联系 Block：飞书、X / Twitter、邮箱和 GitHub；均由用户主动填写。
- 个人资料编辑、图片上传、编辑与删除 Block。
- 自动保存到浏览器 `localStorage`。
- 发布到 ViceMe 后通过 `context.read` 自动使用作者名称、头像、简介和站内作品，通过
  `navigation.open` 打开对应作品；用户补充的外部联系方式仍保存在页面内容里。
- 桌面与手机响应式布局。

## 运行

```bash
npm install
npm run dev
```

构建生产包：

```bash
npm run build
```

## 作为模板复用

1. 把整个目录复制到用户工作区，不另建页面或替换技术栈。
2. 先完整阅读 `DESIGN.md`，再运行 `npm ci` 与 `npm run dev`（需要 Node.js 20.19+
   或 22.12+）。
3. 打开终端显示的本地地址，用现有界面替换示例资料、作品链接、联系方式、封面和头像。
4. 直接展示供应源码运行出来的页面；源码结构和 `src/styles.css` 是唯一视觉依据，不看图重做。
5. 内容会自动保存到当前浏览器；`npm run build` 会把上传所需的 manifest 一起放进 `dist`，
   当前 AI 直接使用既有自定义作者页流程上传构建产物。

## 边界

- 这是前端本地模板，压缩包包含 `index.html`、完整源码与依赖锁定文件；不含 `node_modules`，首次运行需执行 `npm install`。
- 不提供 JSON 配置导入功能；用户可直接在页面中填写和上传自己的公开资料，以复用同一版式和交互。
- 不含登录、数据库、部署服务或数据抓取。
- 不提供视频、文字、图片墙或其他 Block；媒体在本期特指公开联系方式。
- 联系方式不做自动抓取；链接和邮箱仅作为用户主动添加的公开入口。
- 公开发布时请继续使用自己的名称、图标和文案，不要以 Bonjour 官方模板或合作产品进行宣传。
