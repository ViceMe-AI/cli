# 做同款创作者体验约定

本次仅处理刘树负责的创作者体验项。来源为[问题账本](https://connect-ai.feishu.cn/wiki/PpS1wZP52iXLUxk0ioycL5FZnkh)及本次讨论确认；WorkBuddy 工具以[内置工具文档](https://connect-ai.feishu.cn/docx/W1Eodp4iXoRsZOx8T8LcSy8jn5g)和宿主实际暴露的 schema 为准。

## 已确认行为

1. 保留现有按钮样式及默认点击直接复制交互。Skill 教创作者通过自然语言自定义所有按钮、文案、样式、位置和出现时机；只保留对应作品的权威网站路径。邀请给 Agent 的参考路径使用该作品 `.md` 地址，邀请句式可改。没有自定义要求就不换样式、不添加弹窗。
2. 首次接入及每次修改后，WorkBuddy 主动通过 `present_files` 展示真实页面；未发布按钮在右侧预览中可见、可点击提示，不能复制假口令。每次修改使用新的预览标识。创作者确认效果后才发布或更新；已有且未变化的确认复用，模型自动测试不能代替真人确认。
3. 缺少必要输入时，WorkBuddy 优先使用 `AskUserQuestion`，定价在一张卡片中提供档位及原生自定义金额。用户已提供的信息不重复问；更新时未要求改价就沿用现价。工具不可用时如实说明并退回宿主可用方式。
4. 删除无关推荐、推广素材和是否留言等额外询问。效果说明及发布摘要先分行展示在对话正文，提问框只保留一句简短确认（例如“是否确认发布？”）和“同意”“拒绝”两个预设选项，保留工具原生自定义输入，不另加“自定义”选项。拒绝时停止本次待确认动作；自定义意见按语义处理，修改后刷新受影响的预览或终审并确认。缺少价格等信息仍用定价卡。发布终审仍需真实确认，不能把减少提问当成自动批准。
5. 下载的 SOURCE 不包含原作者做同款按钮、复制及弹出逻辑。Agent 标记完整代码边界，CLI 从目录或 ZIP 的冻结交付副本移除。保留创作者原项目、原 ZIP，以及署名、许可证、赞赏和弹幕；历史不可变版本需正常发布修正版本。完整安全检查先于移除。终审提供移除回执，旧 CLI 无回执时停止确认。
6. 发布后直接告知可以与 Agent 对话查询销量及收入。`viceme replica analytics <work-url>` 使用当前 Profile 验证作品所有者权限，再带身份实时读取作品 MD。CLI 不向 Agent 暴露登录凭据；无权限或读取失败不能回退公共数据、旧数字或虚构零值。Agent 只使用平台 OWNER 经营区，说明实际统计口径。
7. 完成反馈仅保留作品预览、邀请口令、对话查询经营数据提示和适用的服务号通知说明。必要故障如实说明，不展示内部 ID、哈希或恢复命令，也不承诺未确认的通知能力。

## 实现与验证边界

- 改动所有者是 CLI 的官方 Skill、源码冻结模块及 CLI API 适配；平台托管按钮和默认 UI 不修改。
- 三个已确认测试边界：Skill 的按钮预览与复制规则；公开源码冻结接口产出的实际 ZIP；公开 CLI 命令的身份与实时 MD 请求。
- 代码审查基线为同步 `origin/dev` 后的 `3df3f3f9f9937eff1cf1cf48a4267abc7e5ac258`。
- 自动化使用临时项目、ZIP 和本地 HTTP 服务；不使用真实账号数据、不发布作品、不覆盖本机已安装 CLI 或 Skills。
- WorkBuddy 真人预览及正式环境验收另行记录；本地测试通过不代表问题账本已验收，不据此改为“已解决”。
