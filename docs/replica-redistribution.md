# 做同款再发布与来源

获取源码不等于获得二次分发或转售权。仅当上游在该笔订单创建时已开放再分发，且订单已付款、权益有效，才可以在 ViceMe 再次发布。

1. 使用 `viceme replica redistribution-grants` 查询当前账号权益。只选 `canRedistribute: true` 且与实际源作品一致的条目；有 `nextCursor` 时以 `--cursor` 翻页。
2. 新作品沿用 `viceme replica publish` 的预览及确认流程，增加 `--source-entitlement <entitlementId>`。该来源纳入最终确认，不能在确认后替换。后端核验权益归属、付款及授权，拒绝他人权益和无授权权益。
3. 发布成功后主动询问创作者是否允许下一层继续分发；在结果 `statusUrl` 页面选择。新作品默认关闭，不替创作者自动开启。上游关闭不撤销已经获得的授权。
4. 更新已有再发布作品不需要重新选择来源，后端保留原来源；不得更换来源或冒充原创作品。不得删除或规避订单溯源标记。

来源链仅包含平台内通过此流程成功再发布的作品，不承诺识别所有站外传播或故意隐瞒来源的上传。授权不包含平台外分发或转售。

## 发布顺序

本次 CLI 增加可选许可证字段识别，旧许可证继续有效。应先发布兼容 CLI，再上线 Shop 的授权开关；旧 CLI 不认识新授权许可证时必须升级，不能通过删除字段绕过签名校验。Shop、CLI 的合并及正式发布需分别验证。
